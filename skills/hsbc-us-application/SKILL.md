# 美国汇丰申请辅助

目标是用申请人的真实资料减少返工，并以银行回执确定当前状态。此 Skill 来自一次已提交、待审核的实操，尚无获批速度或通用成功率证据。

## 开始前

1. 先检查现有申请页面。已有提交回执时进入补件跟进，不重新申请。旧标签、旧二维码和旧成功记录不能证明当前会话有效。
2. 实时阅读[官方开户 FAQ](https://www.us.hsbc.com/account-opening/frequently-asked-questions/)及[费用条款](https://www.us.hsbc.com/content/dam/hsbc/us/docs/pdf/deposit-terms-and-charges/hsbc_premier_tcs.pdf)，核对所在地区、材料、费用和产品。不要把个人经历变成资格保证。
3. 在打开有超时限制的表单之前，使用 [资料预检模板](references/intake.md) 收齐影响后续填写的事实。实际资料只能存入本人授权的私人目录。当前 Skill、公开示例和可分享包保持无个人数据。
4. 明确自动填写、文件上传的目标与已授权数据范围。验证码、拍摄和活体核验由本人完成；本人阅读接受声明和最终开户提交。复用当前会话的明确授权，避免重复提问。

## 地址证明的来源

已有银行关系时先查看已出具的正式电子月结单，核对本人姓名、真实完整地址和日期。可按申请页要求选择正式水、电等公用事业账单；缺姓名或地址的缴费成功截图不能默认满足要求。

国内Premier达标、账单生成、美国地址证明审核是三个不同状态。不要把“50万元存满一个月”当作统一出账条件，也不要从一份账单推导美国账户资格或免月费。汇丰中国APP当前参考路径为全部功能 → 文件中心 → 电子账单，使用前核对[官方说明](https://www.hsbc.com.cn/en-cn/ways-to-bank/online/faq/)。近3个月是本次观察到的表单要求，后续以实时页面为准。

## 材料与填写

- 原始 PDF 优先。核对姓名、完整地址、邮编、出具日期、全部页、加密情况、格式和大小；当前页面的限制优先于旧记录。乱码 PDF 使用可视化核验，不把乱码当缺字段。
- 证件列表截图可辅助提取资料，不能代替银行要求拍摄的原始护照。二维码含临时验证信息，不加入归档或教程。
- 地址或邮编与证明不一致时，列出具体差异并请本人确认真实版本；不能只为通过校验改造材料。仅缩写英文地址以适配长度，不能省去房号等定位信息。
- 姓名按护照拼写。税务居民地、美国身份、过去年度居留、FTIN 与美国 SSN/ITIN 分开问，不照搬教程里的全选否。需税法解释时核对官方规则；不确定就保留待确认。
- 资金来源、首笔金额、汇出地区、预计余额、现金和国际汇款频率分别填写。币种和金额由本人确认；不要把本案例的金额、雇主、国籍或卡片偏好写成默认答案。
- 选项只有区间时，保存用户原意与选择的区间。复核页若显示固定代表金额，要告知并核对，而非声称银行支持了不存在的精确区间。
- 每页填写后读取页面状态，依据实际标签操作。不要复制历史选择器、tab ID 或隐藏业务接口。材料不足时先在表单外补齐，避免超时。

## 失败与恢复

- 超时：先确认有无回执或恢复入口。确实丢失且未提交，才用已确认资料重填；不要重复申请已经提交的案件。
- 身份验证失败：记录页面原文，找当前可见重试入口；最多返回核对一次。若页面提示稍后验证且允许继续，则保留未验证状态并前进，不无限刷新或重建申请。闭眼、网络、摄像头都不能仅凭猜测定因。
- 同意按钮报错：读取具体缺项。可先打开披露文件供本人阅读。Opened 只代表链接打开，不能替本人声明已接受；不要绕过校验或脚本修改状态。
- 编辑地址、余额等应在复核页完成。最终声明页可能没有返回编辑入口，不能假设浏览器后退能恢复。

## 提交和后续

本人提交后核对成功标题、申请编号、状态和银行给出的时限，保存私有回执。区分已填、已上传、已提交、需补件、已获批、已入金、费用豁免已生效。页面说会在若干工作日联系不等于承诺届时开户。

仅按实际补件通知准备和上传材料。没有邮件访问就明确未查邮箱，不说没有新邮件。全球 Premier 关系、Home Bank 和美国费用豁免需要银行确认；账户在 App 可见或暂未扣费不能作为长期豁免证明。开户和汇款分开授权。

## 可分享复盘

使用 [状态与计时规则](references/status-and-timing.md)。正文、图片、HTML、文件名及压缩包都不包含姓名、证件、住址、电话、邮箱、账户、申请编号、二维码、会话链接或真实账单。用信息卡表达经验，原件保留在私有档案。不要发布到社交平台或公开仓库，除非用户明确授权该目的地。
