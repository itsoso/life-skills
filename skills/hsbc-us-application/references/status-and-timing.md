# 状态及计时

| 观察到的证据 | 可以报告 | 不能报告 |
| --- | --- | --- |
| 文件上传后进入下一步 | 上传流程已完成 | 文件审核通过 |
| 暂时无法验证 ID，稍后要求验证 | 身份核验待完成 | 已验证 / 已拒绝 |
| This step has already been completed | 该步骤不可重入 | 身份验证通过 |
| 感谢申请 + 编号 + 后续联系说明 | 申请成功提交，等待检查 | 账户已开通 |
| 正式开户通知 / 可核对的账户状态 | 账户已开通 | 长期费用豁免生效 |
| 银行明确确认全球身份及费用安排 | 相应安排已确认 | 所有市场永远免费 |

计时以原始事件时间戳为依据，统一时区，保留起止事件及计算口径：

- 总历时：首次申请请求至首次读取成功回执，包含跨日等待。
- 当日跨度：当天恢复办理至回执，包含查资料、研究、沟通和中断。
- 最后一轮：有证据的最近一次恢复确认至回执；若起点在验证码之后，就明确排除验证码耗时。
- 纯操作工时：没有连续可验证日志就标记不可准确分离。
- 审核耗时：未获批不能计算；承诺联系窗口不是审批完成时间。

单个案例的最后一轮很短，不能推导别人必然能在相同时间完成。效率收益应写成减少缺件、重复确认和超时返工，除非有对照测量。
