# 表单前预检

此表为空白模板。填写后的版本属于个人敏感资料，不保存回 Skill。

| 主题 | 需要本人确认的内容 | 来源 | 状态 |
| --- | --- | --- | --- |
| 申请背景 | 当前所在地区、赴美计划、产品、现有汇丰关系 | 本人 / 官方材料 | 待确认 |
| 身份 | 护照姓名、出生日期、国籍、证件号及有效期；美国出生、国籍、绿卡等 | 护照 / 本人 | 待确认 |
| 联系 | 本人长期使用的邮箱、手机号与国家代码 | 本人 | 待确认 |
| 地址 | 居住、邮寄、永久地址；邮编；英文缩写及长度限制 | 本人 / 正式证明 | 待确认 |
| 证明 | 完整有效护照，当前页面允许的近期住址证明 | 原件 / 完整 PDF | 待确认 |
| 就业 | 就业状态、职务、雇主及国家、业务控制身份、推荐关系 | 本人 | 待确认 |
| 税务 | 所有税务居民地、各地税号、美国身份与相关年度在美天数 | 本人 / 官方规则 | 待确认 |
| 资金 | 用途、财富来源、首笔与后续来源、汇出地区、金额和币种、预计余额区间 | 本人 | 待确认 |
| 交易 | 现金频率、每月国际汇款预期及问题排除项 | 本人 | 待确认 |
| 偏好 | 网银注册、借记卡、其他产品 | 本人 | 待确认 |

资料已足够时直接继续，不反复询问。缺项只问影响下一步的事实。
