# 香港手机号办理与保号

将用户带到可验证的结果：取得自己的香港号码、确认激活与实名状态、实测需要的短信服务、记录号码有效期。只要教程时交付教程，不自动开户；已有运营商或套餐选择时沿用，不强行推荐 SoSIM。

## 先识别实际条件

从已有上下文提取，只追问缺失且影响选择的信息：当前所在地；设备型号、销售地区及 eSIM 支持；用途是验证码、通话还是流量；是否已有号码；预算。实名所需证件类型按运营商当前页面确认，不默认申请人有香港身份证，不索取完整证件号码供方案筛选。

eSIM 支持不能只凭“港版”或某代 iPhone 推断。核对厂商当前规格与设备“添加 eSIM”入口/EID；存在运营商锁或地区限制时进一步确认。不能使用 eSIM 时，改查实体卡获取和首次激活条件，不把购买 eSIM 当作通用解法。

## 购买前核验

优先打开所选套餐的官方具体页面及适用条款，记录核查日期。SoSIM 核验要点和官方入口见 [references/sosim.md](references/sosim.md)，仅在选择或比较 SoSIM 时读取。

确认套餐具有 +852 电话号码及短信功能，不能用纯数据旅游 eSIM 代替。分别核对：

- 购买价和结算币种、号码与套餐有效期、有效期从购买还是激活计算。
- 能否在用户所在地首次激活、何时必须完成实名、所需证件与操作方式。
- 当地接收短信、接听及拨打电话的费用；“有短信功能”不保证银行或其他目标平台接受号码。
- 是否自动续购套餐、触发条件、取消入口；充值延长号码的门槛及起算方式。

页面与邮件冲突时按具体订单解释差异，不能把个别赠送流量推广为固定权益。新客优惠的资格、转换期限只适用于对应套餐。官方证据不够就标注待确认，不据旧经验断言可用。

## 协助申请与验收

按用户授权范围协助选择套餐和准备订单。沿用当前环境的付款、条款和实名操作权限规则；本 Skill 不增加付款、接受协议或上传证件授权。付款失败时先核对订单和扣款记录，避免重复支付。验证码、实名验证及安全挑战不绕过；需要用户在手机操作时给出当前步骤。

购买成功后，按运营商邮件和设备入口安装 eSIM 或插卡，按官方指引连接网络并激活。不要把“邮件已发”写成“安装成功”。配置数据线路前说明会使用哪张卡的流量，保留用户原主卡设置。

分别核实并报告：

1. 订单/购买状态。
2. 激活确认和分配号码。
3. 实名登记结果。提交成功不等于审核通过。
4. 普通短信与目标服务验证码实测结果。平台注册成功若不能确定验证渠道，不推断短信已实测。
5. SIM/号码到期日、各流量包到期日、自动续购开关状态。

使用允许的浏览器、账户或邮件工具读取必要证据；没有工具时请用户自行查看或提供脱敏页面。不要扫描无关邮箱、证件或历史文件。公开稿不含完整号码、邮箱、证件号、ICCID、EID、安装二维码、验证码、订单号或带令牌的链接。

## 保号与提醒

号码有效期、流量包有效期、账户余额分别处理。关闭流量包自动续购不等于注销号码，开着自动续购也不证明余额足够或保号成功。建议按用途检查不需要的香港流量包自动续购，未经授权不修改。

依据账户或官方确认邮件中的号码到期时间安排提醒。用户要求提醒时，默认建议提前 30 天和 7 天，明确时区；用实际可用的任务工具创建并回读，无法创建就如实说明。首次开卡价不是下一年固定保号价。充值后核对新到期日，再更新提醒，不能无条件年年沿用旧日期。到期日不明时只能设置标注“待核实”的检查提醒，不能把购买日加一年写成已核实日期。

## 交付

给出适合用户的路线、官方来源和核查日期；已执行任务另附各阶段真实状态及下一步。公开分享以实际经历为主，将通用操作与个人结果分开，不承诺人人成功、所有设备可用或最低成本。Skill 是指导流程，能否实际代操作取决于运行环境及用户授权。
